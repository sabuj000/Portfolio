Docs-as-Code Documentation Toolkit

A reusable set of AI skills that create and review product documentation — user guides, KB, API, use-case, and release notes — from any input (Word, PDF, Notion, Jira, Google Doc, or text). Configurable to any product, self-serve, with zero company-specific content.

🛠️ Generate your config View on GitHub
What it is

Docs-as-code, run by skills

Point the skills at your product, repo, and sources. They ingest any source, verify claims against your code/spec/tickets, draft in your format, run a quality gate, and deliver — or review an existing doc/PR.

🧭

Orchestrator

One entry point: detect input → classify doc type → route to the right create skill → auto self-review → deliver.

✍️

Create skills

User docs, KB articles, API reference, use-case/implementation guides, and release notes — each owns only its structure.

🔍

Review skill

Reviews a draft or PR against the same quality gate — with apply-suggestions, verdicts, and must/should/nit findings.

♻️

Shared modules

Ingest, verify (source of truth), quality checklist, style guide, terminology, deliver — written once, reused everywhere.

⚙️

Self-serve setup

An interactive setup builds your project-profile.md — the single file that configures everything.

🛡️

Trustworthy by design

No invention; unverifiable claims flagged [unverified]; retrieval-ready for humans and AI alike.

Architecture

One pipeline, shared logic

Create skills are thin — they compose the same shared modules, so behavior stays consistent and it's easy to extend.

Install

Get started in three steps

1. Get the toolkit and drop skills/ where your AI assistant looks for skills.

git clone https://github.com/sabuj000/Portfolio.git
cp -r Portfolio/docs-toolkit /path/to/your/docs-repo/docs-toolkit

2. Save your generated config as docs-toolkit/project-profile.md, and copy shared/terminology.example.md → shared/terminology.md and add your brand terms.

3. Ask your assistant to “write a doc from this…” or “review this PR…” — the docs orchestrator takes it from there. Or run the docs-setup skill to build the config interactively.
