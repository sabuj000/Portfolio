Try the Arena API

Arena is a fictional API I made to demonstrate a docs-as-code workflow. It has no hosted server, so the requests below go to a sandbox that runs in your browser. It implements all 28 operations in the API reference, and contract tests check it against the OpenAPI spec.

Any sk_test_… key works. A pk_test_… key is read-only.

Response
Pick an operation and send it. Example IDs are replaced with ones that exist in the sandbox.

Data stays in this browser. The sandbox has no webhooks or rate limits. Source: arena-game · SDKs and sandbox · Play the demo games
